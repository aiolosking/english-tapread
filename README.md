# english-tapread

北师大版英语五年级上册 Unit 1 Jobs 点读网页。
在线访问见 GitHub Pages。

---

## 使用说明

一句话：打开链接，点课本图上的气泡或右侧句子，即点即读**原声**并高亮；支持整课连播、暂停、单句重复、跟读、停止。

> 在线访问（免登录，手机 / 平板 / 电脑均可）：
> **https://aiolosking.github.io/english-tapread/**

### 这是什么

把北师大版英语五年级上册 Unit 1《Jobs》的课本页面图片与配套原录音，做成一个可点读的网页：
每一句课文、单词在课本图上有一个可点的热区气泡，右侧同步列出句子清单；点任意一处，就播放这一句的**原录音**，并高亮它所在的位置。

### 怎么打开

- 直接用浏览器打开上面的在线链接即可，无需安装、无需登录、无需账号。
- 想离线使用：把本仓库下载或克隆到本地，双击 `index.html` 打开（图片与音频都是相对路径，跟仓库一起下载就能用）。

### 怎么用

1. **点读**：点课本图上的气泡，或点右侧句子列表里的任意一句 → 播放该句原声，同时高亮当前句。
2. **翻页**：页面上方可切换课本页；连播时也会自动翻到下一页。
3. **控制条**：
   - **整课连播**：从当前句开始按顺序把整课读完，读完自动翻页；
   - **暂停 / 继续**：随时暂停，再点继续（跟读的停顿中也能暂停）；
   - **单句重复**：反复循环当前这一句，适合跟读模仿；
   - **跟读**：播放一句后留一段停顿给你跟读，再自动进入下一句；
   - **停止**：停止播放并清除高亮。
4. 切换句子时会自动停掉上一句，**不会出现两个声音重叠**。

### 页面标记说明

- 带琥珀色"**答案**"徽章的条目是练习答案，只作对照用；
- **没有播放按钮**的条目，表示配套录音里没有这一句（无音频），不会给假按钮；
- 热区按百分比定位，页面放大缩小、换手机或电脑屏幕后，依然对准原句位置。

### 声音来源（重要）

- 全部音频为**教材配套原录音逐句切分**：保留每句完整首尾、不混入相邻句子；
- **没有使用任何 AI 合成语音**补齐；
- 个别孤立单词、歌曲段机器难以自动核对的，制作时已人工试听确认；无法确认的条目如实标为"无音频"。
